# Monkepedia catalogue notes

The launcher includes a compact index of Ape Escape stage and monkey labels. Personality descriptions and extracted in-game profile artwork are omitted. Entries not checked against the North American SCUS-94423 release are marked Unverified entry rather than assigned an invented name.

Stage and character labels were cross-checked against the community-maintained [Ape Escape Wiki — Monkepedia](https://apeescape.fandom.com/wiki/Monkepedia). The source page identifies its community content as available under CC BY-SA; see that page for the applicable terms. This partial index does not claim that every alternate regional label or memory mapping is verified.
