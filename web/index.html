Ape Escape Recompiled

An early browser build of Ape Escape Recompiled - Enhanced Edition. Pick a game image you own, then launch the experimental runtime in the canvas below.

The commercial game is not included. The image is copied into browser memory for this session and is not uploaded. Large disc images need substantial RAM; use a desktop browser with plenty of memory for the first test.
Choose your own CHD image to begin.
Click the game screen to focus it. SDL browser input and compatible gamepads depend on the browser/device.
