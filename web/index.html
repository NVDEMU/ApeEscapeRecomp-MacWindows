Experimental browser port · WebAssembly

Ape Escape Recompiled

An early browser build of Ape Escape Recompiled - Enhanced Edition. Select your own disc image and the matching SCPH-1001 BIOS dump, then launch the experimental runtime.

The commercial game is not included. The disc image is kept in browser memory for this session and is not uploaded. Use a desktop browser with ample free RAM.
This build was compiled for SCPH-1001 specifically. Select your own legally dumped, 512 KiB BIOS from that model. BIOS data stays in this browser session and is never uploaded.
Choose both your CHD disc image and matching SCPH-1001 BIOS dump.
